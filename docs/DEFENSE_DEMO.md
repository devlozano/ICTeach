# Defense demo and rehearsal script

Use a dedicated demonstration class and consenting test accounts. Confirm the real defense date with the team; the copied checklist's 2024 dates are stale.

1. Explain the TVL-ICT CSS learning problem and the roles of student, teacher, trainer and admin.
2. Show teacher/trainer web login, a class, published modules and the class QR/join code.
3. Switch to the Android student account. Join the demonstration class and complete the readiness diagnostic.
4. Open a module, mark it done, and show the persisted progress after reopening.
5. Show a quiz submission and its result; demonstrate that a saved result cannot be replaced by a retake.
6. Demonstrate PC assembly and one network simulation. Use an account whose prerequisite labs have been passed before the presentation.
7. Demonstrate a live lock from the teacher/trainer screen while the student is viewing an activity, then unlock and reopen it.
8. Show a forum post containing a pre-approved image and a reply from another test account.
9. Open Class Insights: show performance bars, diagnostic results, an evidence-based practical review and CSV export.
10. Show the admin content inventory and explain the distinction between instructional competency records and formal TESDA certification.

Before rehearsal, capture screenshots or a short recording of the tested flows for the offline backup. Do not claim the backend is hardened or the site is deployed until those release checks are complete. Assign narration, Android demo, staff demo, technical questions, evidence gathering and backup operation to named team members.

Prepare answers about assessment validity, CSS alignment, access control, data protection, scoring, limits of simulation, internet dependence, testing coverage and the distinction between implementation and measured learner outcomes.
